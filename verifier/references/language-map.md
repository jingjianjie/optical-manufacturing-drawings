# 用语网络与旧名称映射

概念定义在包内 [GLOSSARY.md](../GLOSSARY.md)。本页连接概念、旧图样用语及实现字段；使用本包无需另装language skill。

## 概念关系

- 独立单片、胶合子片、胶合组件分别对应单片图、子片图、胶合总图。组件由子片组成，胶合界面关联相邻子片。
- 图内面号映射源面号；光学面分为胶合面、镀膜面、不镀膜面。共享界面在不同图中可能有不同局部编号。
- 每个面分别有有效通光边界、曲面截止边界；工件另有机械外圆。平台、倒角、胶合覆盖区不能代替这些边界。
- 图样模板包含图框、标题栏、材料要求表、零件要求表、面参数表、材料明细表、技术要求区；修改一个区域不隐含修改其他区域。
- 源模型与项目要求形成制造图；图面生成完成后进入独立复核，声明范围通过后形成正式交付包。制造验收另需实物证据。

## 实现与历史名称

|实现/历史名称|统一含义|边界|
|---|---|---|
|`单片` / `singlet`|独立单片|对应单片图；枚举保留兼容|
|`单片:子片` / `cemented-element`|胶合子片|对应子片图；勿套总图清空策略|
|`胶合件` / `cemented-assembly`|胶合组件|对应胶合总图|
|`surfaces[].radius`|带符号曲率半径|不是机械外半径|
|`mechanical.parts[].radius`|机械外半径|乘2为机械外径|
|`ca` / `SemiDiameter`|通光半径|图面Ø、D01/D02用两倍；CA单独出现需辨半径/直径|
|`mechanical` / `MechanicalSemiDiameter`|机械半径|不同数据层不凭字段名猜含义|
|`curve_end`|母曲面截止半径|图面截止直径为两倍|
|渲染器`胶合Ø`|名义胶合覆盖直径|当前算法取两侧倒角起点直径较小值，不是实测胶层|
|`front/back`|内部面索引|本格式加1映射源面号，不是通用ZOS规则|
|`local: S1/S2/S3`|图内面号|单片/子片D02对应S2，双胶合总图D02对应S3|
|`scratch_dig`、模板`surface_quality`、历史图注“光洁度”|此处为表面疵病要求|不解释为粗糙度|
|`N`、`delta_N`、`delta_R`、`B`、`C`|历史图框要求栏代号|按所采用标准体系解释，不擅自换算等级|
|本项目`B` / `C`|表面疵病要求 / 光学偏心要求|60/40是B栏的数对，不能把B/C两栏叫划痕/麻点；C当前为<3′|
|`polished_mark`、`polished_block`、`OMD_POLISHED_CROSS`、`POLISHED_MARK`|减反射膜圆十字符号的旧实现名称|仅对镀膜面使用；旧名字不决定物理意义|
|`assembly_tables.material_values/part_values`|材料要求表/零件要求表的填写开关|不控制底部面参数表/材料明细表|
|`aperture_table_y/material_table_y`|面参数表/材料明细表纵向位置|不代表列宽、字号、显示开关已全部可配|
|`effective_spec`|本轮逐页有效项目要求|历史例子不能覆盖已确认修正|
|PDF结果键`complete`|合订PDF路径|不代表复核完成或制造合格|
|`PASS / FAIL / UNVERIFIED / N/A`|声明范围通过／已证实不符合／未能核实／不适用|报告存在不自动等于PASS|

旧字段和枚举是兼容接口，宜整体迁移并验证调用方后再更名。本次统一不改已交付图纸、JSON结构或脚本调用协议。

## 边界场景

1. 通光半径12.45在图面是Ø24.90，不能直接写Ø12.45。
2. 总图D02对应外露S3，子片B的D02对应其局部S2；两者可以是同一个源面。
3. 材料要求表留`-`、零件要求表填写，不会删除材料明细表；这是三个区域。
4. 删除Rmax不改变Ravg；镀膜400–700nm不证明设计400–650nm外的像质已验证。
5. 通光边界到倒角起点的径向余量0.1mm，与外径到通光边界的余量不同；均不能直接证明装配公差足够。
6. 胶合面不镀膜仍可以有倒角；外露平台涂黑不延伸到胶合区。
7. “光洁度60/40”按当前项目疵病条款读取，不将数对填入粗糙度栏；标准体系不同不直接换算。
8. 文件生成完成、报告已登记、声明范围通过和实物合格分别表达，不逐级自动升级。

## 维护方式

新词先比对词汇表；不同概念记录区别，同义旧名加入映射。源标准引文、历史图注与程序枚举不做机械替换。定义与代码不符时说明实际行为与差异，不将理想描述冒充已实现能力。

两份skill各自携带同版GLOSSARY.md和本页，无外部软链接依赖。共享词义更新时同步两包并比对内容；执行步骤仍归各自文档，不复制整个制图包到verifier。
