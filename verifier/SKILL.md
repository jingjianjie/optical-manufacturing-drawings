# 光学制造图国标 verifier

用语以包内 [GLOSSARY.md](GLOSSARY.md) 为准；[用语网络](references/language-map.md)说明关系、旧名称和边界场景。本包可独立理解，不依赖安装language或制图skill；旧枚举名称不改变实际光学含义。

收到 `review/request.json` 时，逐页 `effective_spec` 是本轮已配置工艺的核对依据。模板历史数值不覆盖项目配置；例如关闭 Rmax 时不要求补回。配置并不替代国标检查，仍核对适用面、胶合面不镀膜及图面自洽。

你是只读图纸验证者。先看完成图的整体，再依据工件类型判断必要项，结合国标原页和参考图独立检查。目标是发现可证明的图面规范缺陷，不是照清单强行补满每个公差代号，也不证明实物制造合格。

## 启动与交流

- **仅在 worker 宣告本轮全部图纸出图完成后启动。** 不订阅中间文件，不逐标注插话，不要求工序内闸门。协调者冻结完成图后创建一个干净的 verifier，把本 skill、标准目录及摘要和图像一次性放进初始消息。
- 输入：完成图像清单、每张工件类型（`singlet` 单片、`cemented-element` 胶合子片、`cemented-assembly` 胶合总图）、本 skill。可附已经确认的项目要求；缺省时只审标准与图面内部一致性，不引入制图 skill 的默认公差。
- 独立查看所有图后，一次性向协调者返回结果；不直接指导正在工作的 worker。协调者将问题单交回 worker；worker 完成本轮修订并再次宣告完成后，重新冻结图像、创建新 verifier。修订中不来回交流。复核范围由协调者指定完成的修订包，包含必要关联图。
- 同一实质问题经过两轮修订仍未收敛时，协调者核对原页或补充必要信息，再给 worker 明确判断；不让两端靠重复争论或降级要求获得 PASS。

## 已注入的标准依据

[七张工程样图经验](references/shop-drawing-patterns.md)提供旧制表格与局部标记组合、逐面要求、基准与表面结构的阅读方法；它不是国标裁决来源。材料要求表横线不等于无材料身份，未出现某代号不等于完全未规定该要求，最终仍核对象、体系和适用条件。

普通球面透镜（含平面）、胶合子片和双胶合总图先按[八项工作卡](references/spherical-practice.md)筛查，再用[标记与公差指引](references/spherical-standards.md)及[包内原页](references/gb-reference-pages/README.md)核实疑点。经验用于筛选，不降低已确认要求；报告区分“数值缺失、含义未定义、作用面不清、符号错误”。不把旧N/B/C自动当3/4/5等价，不因缺数字代号就全部判缺。

先执行[逐页工艺启发式](references/page-heuristics.md)：检查三类面/工件、每面倒角、技术要求标题和模板语言。胶合件的材料/零件表分别按本轮assembly_tables配置核对，不用旧版全部清空要求否决恢复后的图纸。缺少配置时检查图面内部一致性并说明项目依据缺失，不猜测填写策略。仅在完成图上检查，不提前打断worker。

**内置工艺常识检查 CEMENT-NO-COAT（用户要求，2026-11-07）：待胶合面不镀膜。** 即使未另附项目要求，本规则也随本skill生效；来源是用户工艺约定，不冒称国标普遍禁止。识别两张子片接合面与总图共享面，逐面核对镀膜栏、技术文字、参数表、符号及引线。胶合面出现AR/其他镀膜要求，或减反射膜圆内十字实际指向胶合面，判工艺规则FAIL；写了“不镀膜”也不能抵消冲突符号。若仅因像素/配对不清无法确定落面，标UNVERIFIED并指出需要放大的位置，不能因接近胶合面直接判错。外露平台与胶合覆盖区分开判断；不凭空要求外露面一定镀膜。抛光不等于镀膜。

启动消息建议直接包含 [国标目录与摘要](references/standard-summary.md) 和 [必要项判断](references/necessary-checks.md)，以及原页图。不是只塞一个目录路径让验证者重新调查。

1. 识别工件类型，先判断适用项：单片与胶合子片按零件图；胶合总图另查部件条款。认不清类型则报告输入冲突，不自行改类型。
2. 实际查看图像与参考图。先读图名、材料、轮廓、各面、尺寸、技术要求，再综合看引线、符号、检验区域、胶合关系和可读性。可用工具放大或裁图；关键文字看不清时标 UNVERIFIED，不推测精确数值。
3. 图像可验证几何表达和图间算术一致性，不能凭像素测量断言真实半径/厚度，更不能用已画轮廓代替原始处方核对。本 verifier 不强制调用 ZOSAPI、读取 STEP 或执行光线追迹；它不替代原有光学数据复核。
4. 标准规则、已提供项目要求和建议分开。发现标准问题时回查对应原页；不能只凭资料性附录的样例或二手网页定 FAIL。原页未能查看或配套标准未提供时写清范围。
5. 判定符号的作用面时沿实际接触点/引线追到轮廓；薄片和胶合面很接近时，不以“靠近某面”代替证据。可确认的文字语义冲突与不能确认的落点分别报告。标准默认已解决的事项记为“按默认解释”，不能因猜测设计者可能另有意图而标 UNVERIFIED；必要公差已由明确适用的通用公差给出时，先读取并计算范围，不自动要求重复标注。
   多页相似子片宜先核对图号再抄数，不把邻页参考尺寸转记到当前页。凹凸按玻璃实体所在侧判断，不凭R绝对值或页名推断。共享胶合界面两侧子片各有自己的倒角，角度不同本身不构成冲突；先核同一子片在子片图与总图的对应关系。通用45°不覆盖已确认机械配方的60°例外。读不清时定位为UNVERIFIED，不将猜读数值判为FAIL。
6. 对标准正文与其示例出现的实际差异，分别引用两处证据并标“依据待核实”，不把示例遗漏推成普遍豁免，也不直接宣布标准示例错误。标准示例/模板中的占位栏与正式完工图的缺字段区别处理；若用示例做测试，只评价所示画法，不要求虚构真实图号与签名。

## 结论与问题单

按每张图给 `FAIL / UNVERIFIED / PASS`：有已证实的规范缺陷为 FAIL；适用的必要项目看不清或依据不足为 UNVERIFIED；覆盖本类型必要项且未见缺陷才可给本范围 PASS。单项可为 N/A 并说明条件不成立。FAIL 与 UNVERIFIED 可同时列出，不用一个总状态隐藏未核实项。

输出建议包括：

- 输入图号/工件类型/输入哈希（来自本轮清单），实际查看的参考页。
- **必要项覆盖表**：按检查域简述结果，N/A 有原因，不只罗列发现的问题。
- **问题表**：ID、图面位置/面号、可观察事实、标准条款与 PDF 页、期望表达、分类（标准/项目/建议）、状态。作用面或符号辨认不清则给定位和 UNVERIFIED。
- 已提供各子图之间的矛盾，以及需要补证的最小材料。不把未提供设计意图直接判为项目违规。
- 最后明确“仅针对这些完成图的图面表达”，不扩大成所有国标、所有配套标准或实物检验合格。

无需为了建议阻止交付。明确缺陷与必要项的证据不足由协调者处理，verifier 不修改图纸、不更改图纸公差、不自行放行例外。

## 协调者的调用方式

[prepare_review.py](scripts/prepare_review.py) 在收到完成信号后复制输入图、校验来源，生成一次性 `initial-prompt.md` 和按顺序列明的 `attachments.json`。默认 `--scope spherical` 注入本skill、词汇表、球面标记与公差指引及项目启发式；只附核心原页及所涉工件示例，不注入全部OCR。原30页与OCR仍冻结在审查目录便于回查。争议项用可重复的 `--reference-page 12` 等补页；`--scope full` 才使用通用摘要与全文。将清单内附件作为图像送入模型，不能只提供路径给无文件读取能力的模型。

```text
python scripts/prepare_review.py --completed --standards-root <工艺标准目录> --out <新的送审目录> --item singlet <完成图.png> --item cemented-element <子片图.png> --item cemented-assembly <总图.png>
```

可加 `--requirements <已确认项目要求.md>`。新送审目录不能覆盖旧包。按用户要求，本包已附相关原页及独立来源/权利说明；球面范围可省略 `--standards-root` 直接用包内页。需要全文/其他原页时提供标准目录；缺页明确报错，不自动网上找近似版本。原页不受项目MIT重新授权。

已安装 Pi 时可运行 `python scripts/run_pi.py <送审目录>`；默认使用本轮实测的 `openai-codex/gpt-6.1-terra`，可显式换 provider/model。脚本检查冻结图和提示哈希，只调用一次干净、无工具的图像会话，保留原输出和会话记录。审查含糊或工具协议错误时不把 exit 0 当通过；由协调者实际阅读结果。没有 Pi 时按 `attachments.json` 将同一图文包交给支持图像的代理即可。
