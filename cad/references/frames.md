# 图框提取、分图和模板

先区分用户要可复用空白框、按框拆整张图，还是仅外矩形。能从上下文判断时直接做；不能判断时用总览和范围说明确认。

## 识别和选择

优先寻找图框 INSERT/块定义或布局；炸开图框再检查闭合矩形、长线和标题栏。外框、内框可能在镜片/零件图层，栏目名可能在方框图层，不能按单一图层全选或全删。

用 `ezdxf.bbox` 定位只是候选筛选：文字框/块的 bbox 与视觉不一定完全重合，窗口内完全包含策略会漏跨边界文字和标注。保留 handle 清单并与局部预览核对；分图遇跨框实体要明确归属。

复制实体可用 `ezdxf.addons.Importer`，并 `finalize()` 导入依赖；它对某些对象支持有限。保留布局、块与复杂对象时按支持情况选 ezdxf xref 工具或原生 CAD。导入后验证引用，不仅验证数量。

## 生成空白模板

1. 选择有代表性的完整框。多种框型时分别说明，不把单框模板称为全仓所有框。
2. 保留线框、固定栏目名和必要的企业标识；清除零件图、尺寸、具体牌号/数值/签名。技术要求区的固定条款与本次零件条件要区分，不能把某个镜片的指标推广为默认规范。
3. 新增字段按用户用途设计，原有符号定义不明时保留并注明沿用；不推断材料/光学验收值。
4. 默认保留原坐标和比例。用户需要标准纸幅时明确换算、单位和基点，仅缩放选中的模板。A4 210×297 指模板尺寸，不证明图纸里其他几何的单位。
5. 简单空白模板可以保留可编辑 TEXT/MTEXT；批量填表需求适合使用有稳定 tag 的 ATTDEF/ATTRIB 块。说明当前交付采用哪一种，不能将普通空白区域宣传为自动填表字段。

## DWT

DWT 是 CAD 新建图纸模板，通常采用 DWG 数据结构。最好在目标 CAD 中 SaveAs DWT 并测试从模板新建。没有原生 CAD 时，可把已经回读验证的 DWG 内容保存为 `.dwt` 兼容模板，但须标明没有验证原生模板新建流程，不能宣称包含模板描述/打印机/CTB/页面设置。

同时保留 DWG/DXF 便于打开或交换。给出字体前提、单位/尺度、模型空间或纸空间，以及是否有属性字段和打印设置。
