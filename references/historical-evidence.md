# Provenance and evidence boundary

This workflow was distilled from practical lens-manufacturing drawing work and an independent-agent replay. No real design, historical screenshot, manufacturer template or conversation file is needed to run it.

Public assets are generated from package code: generic A4 grid, simple symbols and synthetic singlet/doublet geometry. They are examples, not reference optical products or official standards. The preserved manufacturing profile is named visible-light-example and requires explicit project adoption.

The replay lessons explain what was learned, not a dependency on the original files. External conceptual sources and their in-package replacements are summarized in [integrated knowledge](integrated-knowledge.md). Third-party libraries and licenses are listed in [THIRD_PARTY.md](../THIRD_PARTY.md).
