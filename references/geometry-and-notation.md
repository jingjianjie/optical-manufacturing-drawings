# 几何、坐标与标注

## 图纸清单

单片：剖面、必要端视/局部放大、材料/技术要求/标注及标题栏。双胶合：子片A图、子片B图、胶合总图；保留相同子片号、胶合界面号，BOM标材料与数量，总图标装配方向、总厚、外径、胶合偏心与胶层要求（给定时）。异径子片各有外径，外露胶合面平台单独尺寸化。

逐图映射：`drawing_id ↔ component_id ↔ subpart_id ↔ ZOS surface indices ↔ local S1/S2`。局部S1/S2用引线指面，不等于原系统面号，需表格映射；胶合总图用S1/S2/S3并保留公共界面。操作见operations.md的R与面号行。

## 建议逐项检查的图面量

- 机械外径、每面有效通光直径、曲面终止直径；单片/子片D01/S1、D02/S2；双胶合总图D01/S1、D02/S3，公共S2另列。与各面机械径独立表达；方法见operations.md。
- 中心厚度、必要边厚/最薄厚度、厚度量取位置；胶合总厚及实际胶层。边厚注明以哪个半径计算、是否扣除倒角，不能将平台边厚当作曲面边厚。
- 两面曲率或平面；非球面必须含面型、圆锥系数及全部系数/单位。不可用一个R描述非球面。
- 平台宽/高度、外圆/曲面过渡倒角或圆角、异径台阶、胶合覆盖直径、墨边和镀膜区。无公差不自动写成公差为0。
- 光学面标识、基准、形位/偏心/楔角、表面质量、面形、粗糙度按本次给定规范标注；必要缺项记在工作记录并补问，不把未决状态留在发布图面。
- 材料与目录、膜层与测试条件、墨层、检验数据、名称/图号/比例/页码/数量。

## 位数与格式

位数和当前公差见[字段与默认](fields-and-defaults.md)及其JSON数值源。建议调用drawing_ops.dimension_value和center_thickness_tolerance，使尺寸与技术条款使用同一解析值。

建议先检查批准名义处方能否按约定位数表达；需改变处方时走已授权设计修调，单纯出图不自动改R/CT。派生sag及平台高度可用括号参考尺寸，母曲率和截止径为主控；全精度API作审计。角度/等级/波段不是毫米尺寸，不按三位量化。

- 图面半径默认 `R`＋正的绝对值，平面标“平面”或∞；引线指向正确曲面。**ZOS带符号R另见处方附表，不从轮廓猜符号。** 若采用带符号R制图体系，整套一致并明确轴向定义。
- 直径用CAD直径符号（%%c或经验证Unicode），不能以小写φ悄悄替换语义。焦距保留负号，正值通常不写+；还原处方可显式带+/-。
- 双向公差用±；非对称公差上下堆叠，上偏差在上，下偏差在下，负号各自保留，例如−0.01/−0.02，不能排成±或把两个负号相消。
- 默认倒角0.200×45°，逐面引线指向真实倒角；例外显式标数。上下偏差用受控TEXT或原生尺寸的叠差，不靠空格拼位置。具体方法见operations.md。
- 毫米/微米、百分比0.25%与小数0.0025不得混淆；镀膜波段是制造要求，不自动改变光学设计波段。

## 坐标转换

顺序LDE的局部+z沿本面坐标，不等于物理传播方向。先读ZOSAPI的面号、带符号R、t、介质以及GetGlobalMatrix的旋转/平移。保存 `p_global = R_surface p_local + T_surface`，并用实际API点验证矩阵排列，不按记忆假定行列。

每个零件选择前顶点为局部原点、零件轴为+z。制造图剖面常取 `x_draw=z_part, y_draw=y_part`，轴对称时截面半径沿±y。全局到零件：`p_part = R_part^T(p_global-T_part)`；再应用图纸旋转/平移。图纸镜像或翻面必须记录，不因“长得好看”丢失方向。翻转轴对称单片时面序倒置且有符号R取反、玻璃区间重映射；在回建中显式验证，不能只把两半径交换。

偏心、倾斜、坐标断点、反射或非轴对称面需保留完整变换/参数，不能靠累计Thickness求全局z；当前简单同轴例子也要记录建模反向F→Q与物理正向Q→F。

模型空间优先1单位=1mm。纸空间/打印比例独立控制；视图在模型空间放大时尺寸实体必须测原零件值并记录比例。模板原始提取曾按1/0.63放大，包内已是A4，不再给镜片施加该变换。检查块插入缩放、OCS/WCS、标注测量值与覆盖文字，不能只看显示数字。

## 符号与线型

需支持：Ø、R、±、°、′、″、Δ、Ⅰ/Ⅱ、上下偏差、表面纹理/粗糙度、基准A、形位框、中心线、剖面线、引线箭头、胶合界面。粗糙度与形位使用CAD实体/块或受控矢量，不用外形相近的Unicode替代未确认符号。

图3/4的单箭头疑似圆跳动、外圆框疑似圆柱度，仅凭截图不能确定标准语义；未取得规范不自动复制0.005。基准圆圈和光学中心符号也不混为一类。光学面粗糙度0.008与非光学1.6/3.2不能相互替换。

实体轮廓实线、非实体有效孔径/光轴等用区分线型；剖面线避开标注，不把小片胶合界面涂没。半径优先解析ARC/带bulge的轮廓；若用采样多段线须记录最大弦高误差，不把折线称为解析球面。

## 原生ZOSAPI几何依据

建议先读[API对齐](api-alignment.md)的CAD行及zos_export.py，再用standalone加载冻结文件。以下是几何证据导出示意，与当前脚本一样不带光线：

```python
tool = oss.Tools.OpenExportCAD()
try:
    tool.FileType = zc.Tools.General.CADFileType.STEP
    tool.OutputFileName = absolute_output_path
    tool.FirstSurface, tool.LastSurface = first_surface, last_surface
    tool.ExportDummySurfaces = True
    tool.DummyThickness = 0.001
    tool.SurfacesAsSolids = True
    tool.NumberOfRays = 0
    tool.Field, tool.Wavelength = 0, primary_wavelength_index
    tool.DeleteVignetted = True
    tool.RunAndWaitForCompletion()
    assert tool.Succeeded
finally:
    tool.Close()
```

这些属性须按实际版本检查存在性并读回；不保证所有面型/版本支持。包含物/像面基准时明确面号及无穷远处理。STEP默认外形若不含独立异径/倒角，报告差异；复杂机械DXF依然与相同顶点/曲率对齐。保持光学CAD与制造CAD两者可区分。
