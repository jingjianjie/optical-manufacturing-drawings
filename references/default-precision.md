# 默认精度与来源说明

按项目维护者提供的说明，默认精度参考**恒洋光学货架镜片的默认精度**，并结合本工作流的制造出图需求进行了项目调整。这里记录的是维护者给定的来源说明，不将本表各项一概标作厂商统一规格。具体订单以工程师采纳的条件为准。

执行值的唯一配置入口为 [drawing-defaults.json](../assets/drawing-defaults.json)，字段语义见 [字段与默认值](fields-and-defaults.md)。调用时先进入问答session确认工艺、公差、精度及覆盖项。

|类别|本包当前默认|说明|
|---|---|---|
|机械直径|上偏差0.00、下偏差−0.02mm|工作流明确采用的覆盖值|
|子片CT≤2.000mm|±0.100mm|薄片加严规则，按CT而非ET判断|
|其他子片CT/胶合总厚|±0.200mm|可以单页覆盖|
|未注线性/角度|±0.050mm / ±0.5°|参考尺寸括号不赋验收公差|
|显示位数|直径2位，其他名义线性尺寸/R/ET/焦距3位|显示精度不等于制造公差|
|材料允差|ΔnD=2B；Δ(nF−nC)=2B|等级语义按工程师采用的规范解释，不换算为Δvd百分比|
|表面|N3、ΔN0.3、40-20、偏心<3′|本包采用的示例等级；测试定义/波长按项目确定|
|倒角|0.200×45°|遇通光或局部曲率限制时逐面列例外|
|涂墨|非通光周边/平台涂黑，参考漆厚0.006mm|避开有效光学区及胶合区域，按约定工序施作|
|镀膜|外露面380–780nm，Ravg<0.25%|胶合面不套空气侧AR；角域/偏振等需项目补充|

这些默认没有替代光学公差分析、供应商工艺确认或工程师最终放行。模型照着表填完不代表该镜头已证明量产良率；可在问答阶段按成本、装夹和性能要求调整。
