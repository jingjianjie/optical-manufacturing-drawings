# 球面透镜制图：光学标记与公差的共同依据

## 范围与证据

仅处理玻璃球面透镜（含平面）、独立单片、胶合子片、双胶合组件及其制造图。不展开非球面、柱面、复曲面、棱镜、晶体、光纤端面或系统布局；激光损伤要求只在项目明确涉及激光时展开。

依据为已存档GB/T 13323—2009《光学制图》，不是对现行版本的重新查询。PDF页04对应印刷页1，文中p均指30页阅读版PDF页码。正文与附录B/C为要求来源，附录A为资料性示例。文件为公开阅读页形成的存档，非官方原生PDF；OCR仅检索，符号和公式看原页。

本文件是释义和执行指引，不是标准全文。GB/T 2831（面形）、7242（中心误差）、1185（疵病）、气泡度相关标准与JB/T 6179（镀膜）完整细则尚未齐备；不从图A.3/A.4的数值倒推通用要求，不把ISO同名标准当作可直接替换版本。表2与4.3.9.4气泡标准编号存在差异，需另核配套原文。

## 先理解：六层要求互不替代

1. **名义几何**：R、外径、CT、平台、倒角，决定画什么实体。
2. **尺寸及中心偏差**：允许偏差、基准或光轴，决定加工装配可偏多少。
3. **面形**：表面相对规定形状的偏差；光圈检验需要波长、口径与表达体系。
4. **表面疵病与表面结构**：划痕/麻点与微观结构不是同一量；5/、P、Rq不能互相代替。
5. **材料特性与缺陷**：牌号、n/ν及允差，另加应力双折射、气泡、均匀性/条纹；2B不自动等于0/或2/数值。
6. **膜层与非光学区域**：AR、涂黑、胶合区及其工艺；圆十字不证明该面已给出抛光、面形或疵病要求。

每条要求应能回答：**对哪个工件/哪个面或区域、按哪个体系、用什么量与单位、限值是什么、何种测试条件**。部分条件可由明确通则提供，无须在每个引线上重复；但不能用一个含糊的“精度”包办全部。

## 单片、子片、总图分别怎么读

**单片/胶合子片**：使用“左表面—材料—右表面”的概念分区（表4，p10）。不强制照搬三列表格布局，但每个表面都能追认R、有效区、面形、中心偏差、疵病、表面结构及膜层是否适用。材料特性/缺陷放材料域，不给左右面复制两份材料身份。

**胶合子片**：待胶合面仍是需要制造和检验的表面。不镀膜≠不抛光≠无面形要求≠无疵病要求≠无倒角。参考图A.4(p21)右表面是待胶合面，仍有P、3/、4/、5/表达；该图具体值不作为新默认。

**双胶合总图**：两个子片件号、不同剖面线方向、相对位置/必要公差、胶合方法、总厚、组件有效焦距与顶点焦距。共享界面作为一个面列示；子片图中同一界面各自有一个制造面。相邻子片可有不同外径/倒角，比较时按“同一子片对应边”核对，不要求两片倒角同角度。

胶后面形/疵病要求不一定逐值照抄胶前；4.2.3注1允许按子片要求作适当增减并按需说明。总图两张旧要求表是否填值是项目版式策略，不是国标要求两表全'-'。当前示例项目当前材料要求表留'-'、零件要求表恢复，子片BOM仍保留。

## Worker：填图前的最小输入单

针对每种工件，先记录 `已给定 / 默认可解释 / 待确认 / 不适用`，不要用空值或'-'掩盖已要求但未定义的项目。

- 每面：源面号、图内面号、球面/平面、凸凹、名义R及其公差表达路径、有效区与检验区关系。
- 每面：面形体系/限值/检验波长、中心偏差及参照、疵病体系/限值/工艺阶段、P/G或粗糙度是否要求。
- 每件材料：牌号、n/ν及参考波长、折射率/色散允差、0/1/2/是否采用及可证实的等级/数值。
- 膜层/边缘：膜种、作用面、波段与指标、已指定工况，涂黑范围，倒角实际机械定义。
- 总图：子片配对、共享界面、组件总厚/公差、相对位置要求、胶合方法、焦距/顶点焦距参考条件。

先集中问未知的验收定义，不逐字段反复追问。设计处方能给R/CA/厚度，不能自动给加工面形、粗糙度或检测体系。用户指定“60/40、N5”是已给数值但未必足以完成国标语义转换；说明缺什么，不默改性能。

操作：用项目配置和机械快照填已实现字段；`technical_text`可承载确认后的说明。当前renderer没有完整的0/–5/、P/G/粗糙度符号生成能力，本指南不代表已经实现这些图块。补新图块应另做小型符号样张、字体与落点测试，再接逐面配置；不要用自由文字伪造完整标准符号。

## Verifier：判断遗漏的顺序

1. 确认图号及工件类型，逐面建立对象清单；先看本图，后看邻片，不凭相似图记数。
2. 分开核对“数值有没有”“语义/体系是否明确”“面与区域是否可追认”“图形符号是否正确”。给出具体缺口，不只写“缺国标符号”。
3. 找通用技术要求、面表、材料表、引线的已有表达。等效表达需要证明，不因有N/B/C就全PASS，也不因没有3/4/5字面就忽视已有信息。
4. 正文明确且可观察的不符合判FAIL；缺配套定义/图像读不清判UNVERIFIED；可由标准默认解释的项注明默认而不追加猜测；无适用条件的项N/A。
5. 原页图只用作画法/条款证据，不复制示例数值；对照表中的未确认项不能由verifier选一个漂亮数值填上。
6. 对双凸片不要套凹面总厚要求；AR符号看实际落面，P与AR独立；共享界面两片倒角差异不直接判矛盾。

报告至少按“面形、中心偏差、疵病、表面结构、材料缺陷、膜层/涂黑、区域、尺寸公差、胶合”九域输出覆盖情况；将国标表达问题、项目要求问题与改进建议分列。
