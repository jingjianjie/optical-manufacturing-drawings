# 图框字段与默认值

## 通用模板与字段坐标
+
+包内generic-a4.dxf由make_template.py从基础实体生成，不读取历史图框。A4竖版、毫米，外框(0,0)–(210,297)、内框(10,10)–(200,287)。没有企业标识、历史签名或实际零件数据。标签和填写位置由renderer约定，不依赖DXF handle。
+
+左上值区中心x=40：ΔnD/Δ(nF−nC)/均匀性/双折射/吸收/条纹/气泡分别y=278/272/266/260/254/248/242；N/ΔN/ΔR/B/C为230/224/218/212/206；D01/D02/f为200/194/188。子片D01/D02对应S1/S2，总图对应外露S1/S3，公共S2另列。材料、实际目录和nd/Vd来自源数据；默认材料栏只显示牌号，详细物性保留在数据/附页，title_material_details开启时需复核格宽。
+
+标题栏主要填写点：名称(110,50)、图号(170,51)、材料(120,26及21)、数量(120,12.5)、阶段(155,35)、重量(177,35)、比例(192,35)、焦距波长(170,21)。签名保留人工填写。尺寸按真实名义值标注，当前视图固定2:1；模板任意替换时同时适配page_renderer字段和纸幅，不宣称通用任意图框布局。
+
+技术条款在页下部由renderer生成，长文本建议使用字体测量和换行。字段来源宜分API、项目指定、已采纳profile和计算值。
+
+## 本session字段来源与默认（用户修订优先）

本工作流建议新出图session开场显示“本次是否按照默认公差要求出图？”并列默认值。已有本轮明确答案时可同时显示“沿用已确认值”并记来源，不重复索要批准；同一session的纠错/微调只记录变化项，新工程复制不等于新问询轮。API、用户明确值、批准默认、计算值建议分别记来源。发布图不含待定/TBD/见面表；必要缺项集中补问，签署留空。

材料ΔnD=2B、Δ(nF−nC)=2B；材料牌号来自API，胶合总图逐片列。材料表其余采用示例图框质量等级2/2/3/3B/3C。零件N3、ΔN0.3、ΔR A、表面质量40-20、偏心<3′。D01/D02按上表填写该图零件前/后端有效径，子片端面可以是胶合面；总图公共S2另列。各面机械径独立列明。f为独立件空气中d线焦距计算值，三位，注明587.562nm。

尺寸规则：除直径两位外，名义线性尺寸、R、CT、ET、倒角及焦距三位。直径上偏差0.00、下偏差−0.02；子片CT≤2.000mm用±0.100，其余CT/胶合总厚±0.200；未注线性±0.050、角度±0.5°。`drawing_ops.center_thickness_tolerance`按名义中心厚自动选择，显式单页公差优先。CT公差优先于通用公差，参考尺寸括号不加验收公差。默认倒角0.200×45°，因CA或局部斜率的例外必须写具体值和原因。

外露光学面镀AR：380–780nm Ravg<0.25%，胶合面除外；非通光周边细磨并涂黑，平台涂墨单独箭头。示例配置采用涂层厚0.006mm、胶合后涂、标注为成品尺寸；若本次另有要求覆盖。采购材料性能等级2B不偷换成Δvd数值。

填写和绘图具体方法统一见[操作索引](operations.md)，可执行默认在assets/drawing-defaults.json，不能只写政策没有可执行路径。旧图中的0.005形位/不同光洁度不自动盖过上述当前默认。

以上数值是供项目采纳的示例惯例，不是通用行业标准；新指令优先。建议从[可执行配置](../assets/drawing-defaults.json)读取，避免复制数值到多个程序。材料允差、S面号/历史圆十字、ET、倒角和涂墨箭头为本工作流图面内容约定；检测数据包括R、CT、独立件/胶合组焦距及面形，镀膜前清洁、牢固附着及膜后无残留污染。

镀膜预留null字段不代表零或默认测试工况；当前脚本支持范围及补充工况的适配路径见[API能力边界](api-alignment.md#当前接口能力边界)。工艺要求可明确写出已有依据，缺少角域/偏振条件时不宣称这些条件已验收。
